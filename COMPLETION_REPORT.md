## 🎯 Design System Specifications

### Color Palette
```
Primary Brown: #78350f (Amber-950) → #d97706 (Amber-700)
Accent: Rose-100, Rose-200
Background: Amber-50, White, Yellow-50
Text: Amber-950, Amber-900, Amber-800
```

### Typography
```
Headers: Font-serif (elegant, classic)
Body: Default sans-serif (readable)
Sizes: 3xl-7xl (headers), base-lg (body)
Weights: 400, 500, 600, 700
```

### Spacing
```
Sections: 16-24 units padding
Cards: 6-10 units padding
Gaps: 6-8 units between items
Margins: 12-20 units between sections
```

### Animations
```
Entrance: 0.6s fade + slide
Hover: Scale 1.02-1.05x + shadow
Scroll: WhileInView with stagger
Timing: 150-200ms between items
```

## 🎯 Quick Start

### To Run Locally
```bash
cd wedding-invitation
npm install
npm run dev
# Opens on http://localhost:5173
```

### To Build for Production
```bash
npm run build
# Creates /dist folder
# Ready to deploy anywhere
```

### To Update Wedding Details
Edit `src/components/data/weddingData.js` and update:
- Couple names
- Wedding date & time
- Venue & location
- Story chapters
- Contact information
- Gallery images

### To Deploy
1. Choose platform (Vercel, Netlify, or traditional)
2. Upload /dist folder
3. Set custom domain
4. Configure DNS
5. Test live site
6. Share with guests
