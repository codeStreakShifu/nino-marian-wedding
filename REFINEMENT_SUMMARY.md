## 🎨 Design System Applied

### Color Palette (Shades of Brown)
- **Primary:** Amber 700-950 (warm brown tones)
- **Accent:** Rose-100 (romantic accent)
- **Background:** Gradient combinations of amber-50, white, yellow-50
- **Text:** Amber-950 (headings), Amber-800/700 (body)

### Typography
- **Headings:** Font-serif (elegant, classic)
- **Body:** Default sans-serif (readable, modern)
- **Sizes:** Responsive with sm/md/lg breakpoints

### Spacing System
- **Sections:** 16-24 units padding (responsive)
- **Cards:** 6-10 units internal padding
- **Gap:** 6-8 units between grid items
- **Margins:** 12-20 units between sections

### Animations
- **Entrance:** Fade + slide up (0.6s, easeOut)
- **Hover:** Scale (1.02-1.05x) + shadow increase
- **Scroll:** WhileInView with staggered children
- **Timing:** 150-200ms between staggered items

## 📋 Customization Guide

### To Update Wedding Details:
1. Edit `src/components/data/weddingData.js`
2. Update couple names, date, venue, story
3. Change contact info and social links
4. Update gallery images (add real image paths)

### To Update Text Content:
1. Hero section text → `Hero.jsx` (currently pulls from data)
2. Story chapters → `weddingData.story` object
3. Couple bios → `weddingData.groomBio` & `weddingData.brideBio`
4. Event message → `weddingData.message`

### To Add Real Images:
1. Replace emoji placeholders in Couple.jsx
2. Update gallery items with real image paths
3. Ensure images are optimized (webp format ideal)
4. Store in `/public/images/` directory

### To Change Colors:
1. Search for "amber" in component files
2. Replace with desired Tailwind color (e.g., "orange", "yellow")
3. Maintain color hierarchy for readability
